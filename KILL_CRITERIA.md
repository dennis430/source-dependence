# Frozen Kill Criteria and Gates

Evaluation plan frozen before results. Amendments prospective only.

## Gate A — Methodological validity (by Day 3)

- Declared invariants and synthetic counterexamples behave as specified.
- Compare against naive source counting, exact deduplication, explicit-root grouping, always-abstain.
- Probabilistic claims (if any) correctly computed on synthetic; wrong/uncalibrated kills that scoring claim.
- Bundle verification rejects altered content, labels unknown trust/missing inputs.

## Gate B — Practical advantage (by Day 7)

- At least three held-out scenario families where richer analysis delivers useful distinction beyond naive counting/exact dedup.
- Ten benign public examples (where lawful).
- Clean-room round trips for bundles.

## Gate C — External usefulness (Day 30)

- Target: ≥3 independent external assessments with ≥2 concrete useful outcomes, OR ≥2 genuine external integrations.
- Founder-controlled and self-consumption do not count.
- If exposure insufficient: UNPROVEN. If no advantage: FROZEN_NO_ADVANTAGE.

States: LIVE_TRIAL, CONTINUE_BOUNDED, FROZEN_UNPROVEN, FROZEN_NO_ADVANTAGE, INVALID_METHOD, PAUSED_ACCESS, PAUSED_BUDGET, ARCHIVED.

Hard stop active experiment workers at Day 90. Preserve public artifacts and authentic records.
